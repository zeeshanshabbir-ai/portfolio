i learned for years and sold nothing

november 8, 2026 • 3 min read

i spent years learning ai tools. not weeks, years. courses, videos, notes, new tools every month. every time something new came out, i went and learned that too. it felt like work. it looked like work. it just wasn't the work that mattered.

the problem was not that i was lazy. the problem was that learning had become the job. finishing a course gave me the same little hit that finishing a product should have given me, so i kept signing up for more. bookmarking more. saving more.

i kept telling myself i was getting ready. one more tool, one more tutorial, and then i would be ready to build something real. but ready never arrived, because there was always one more thing to learn first.

looking back, the loop was simple. learn something, feel good, get excited, start something, get stuck, go learn something else to fix it, and never come back. repeat that for years and you end up knowing a lot about a lot of things, and having nothing to show for it.

what finally changed was embarrassingly small. i stopped trying to learn my way into a sale and started trying to build my way into one. instead of another course, i picked one small, useful thing and built it. badly. then i fixed it in public.

that shift changed how i learn now. i still learn, but only when a real project needs it. if i'm stuck on a workflow, i learn that one piece, use it the same day, and move on. learning is a tool again, not the project.

if you're in the same loop, here's the honest version: you probably already know enough to start. the next course won't fix the part where nothing gets finished. pick the smallest version of the thing you want to make, and make that. the learning will come with it.
