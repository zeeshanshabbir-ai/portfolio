how i run n8n for $0

november 8, 2026 • 4 min read

i wanted to run n8n properly, but i didn't want to pay for hosting before i'd made anything from it. paying a monthly bill for a tool i was still learning felt backwards. so i gave myself a rule: n8n had to cost $0, or i wasn't doing it.

the main piece of the stack is github codespaces. it became my workshop. i can spin up a codespace, run n8n in it, build a workflow, test it, and shut it down again when i'm done. it's not a server that sits there all day. it's a bench i open when i need it and close when i don't.

alongside that, i used vercel for experiments. vercel is where this site lives, and it's where i try out small web pieces that sit next to the automations — a page, a form, a little front end for an idea. nothing fancy, just a place to put things so they have a url.

the third piece is still pending. i applied for serv00, a free hosting option, and i'm waiting on that. i won't pretend it's already working, because it isn't yet. that's part of the honest version of this stack, and it's in the ebook as a pending step, not a finished one.

i wrote it all up in a short ebook called n8n free forever. not because i had it all figured out, but because i'd spent so long piecing the steps together from scattered posts and docs. the ebook is the guide i wished i'd had at the start: what to use, what it costs, and what breaks.

would i run a business on this stack? not yet. if something needs to be up all the time, or hold important data, it needs proper hosting and someone responsible for keeping it running. but that's not what this stack is for. it's for learning, for trying ideas, and for building the first version of something before you pay for it.

the bigger lesson was about constraints. having no budget forced me to understand each piece instead of just paying to make the problem go away. i know what codespaces is good for now, because i actually used it. i know what vercel is good for, because i actually shipped on it. $0 didn't just save money. it made me learn the tools.
