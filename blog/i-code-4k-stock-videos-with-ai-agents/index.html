i code 4k stock videos with ai agents

november 8, 2026 • 4 min read

i make stock videos, but not the way most people do. i don't film anything. i write code that draws movement, then render it in native 4k. the clips are abstract — shapes, light and colour moving in loops — and they are made with remotion, with ai agents helping me write and adjust the code.

there are 360+ clips in the library so far. none of them have people in them. that is a deliberate choice. people in stock footage date fast: clothes, hairstyles, phones, all of it gives the year away. abstract motion doesn't have that problem. a slow gradient or a clean geometric loop can sit in someone's project for years without looking old, and that is exactly what a library is supposed to do.

the workflow is slower than it sounds. i start with an idea — a kind of movement, a mood, a colour — and work with an ai agent to turn it into code. then i watch it, change the timing, change the easing, change the colour until it actually feels good to look at. a lot of the first versions are ugly. the motion is too fast, or too jerky, or too busy. the difference between a clip that works and one that doesn't is usually small: half a second here, a softer curve there. you only find that by watching and fixing, again and again.

then comes the part nobody wants to talk about: organisation. every clip is ai-labelled and kept in dated drive folders, so i can find it again later. that sounds boring, and it is, but a library you can't search is just a pile. when a clip is labelled properly, i know what it is, when i made it, and what it's for. when it isn't, it might as well not exist. i learned that the hard way, after losing good clips inside my own folders.

working with ai agents changed the speed of all this, but not the taste. the agent can write the code fast, and it can make ten variations in the time it would take me to make one. what it can't do is tell me which one is actually good. that part is still mine, and it's the part that matters most. the agent is a pair of fast hands. the eye is still human.

i like this project because it rewards patience. one clip is nothing. three hundred and sixty clips is a catalogue, and a catalogue is an asset. nobody claps for a single abstract loop, and nobody should. the point is the habit: make another one, label it, file it, and do it again tomorrow. slow, quiet, compounding work. that's the whole idea.
