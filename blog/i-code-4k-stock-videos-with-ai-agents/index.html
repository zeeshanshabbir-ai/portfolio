i code 4k stock videos with ai agents

november 8, 2026 • 4 min read

i make stock videos, but not the way most people do. i don't film anything. i write code that draws movement, then render it in native 4k. the clips are abstract — shapes, light and colour moving in loops that never quite repeat the same way twice.

there are 360+ clips in the library so far. none of them have people in them. that is a deliberate choice. people in stock footage date fast: clothes, hairstyles, phones, all of it gives the year away. a shape doesn't age. a gradient doesn't go out of fashion in the same way.

the workflow is slower than it sounds. i start with an idea — a kind of movement, a mood, a colour — and work with an ai agent to turn it into code. then i watch it, change the timing, change the colours, and watch it again. one clip can take an evening. sometimes it takes a week.

then comes the part nobody wants to talk about: organisation. every clip is ai-labelled and kept in dated drive folders, so i can find it again later. that sounds boring, and it is, but a library you can't search is just a pile of files.

working with ai agents changed the speed of all this, but not the taste. the agent can write the code fast, and it can make ten variations in the time it would take me to make one. what it can't do is decide which one is good. that's still the job, and it's the part i enjoy most.

i like this project because it rewards patience. one clip is nothing. three hundred and sixty clips is a catalogue, and a catalogue is an asset. nobody claps for a single abstract loop, and nobody should. the point is the pile, and the pile only grows if you keep going.
